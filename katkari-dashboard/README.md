# Katkari Livelihoods Dashboard

Field practicum board for Suhani Bhatia (TISS), Ambernath & Badlapur, Oct 2026.

## Local

```bash
cd katkari-dashboard
npm install
npm run dev
```

## Deploy on Vercel (browser)

1. Open [vercel.com/new](https://vercel.com/new) in a normal browser tab.
2. Import `suhani-sketch/secretary`.
3. Set **Root Directory** to `katkari-dashboard`.
4. Framework: Vite. Build: `npm run build`. Output: `dist`.
5. Deploy.

If the in-app Vercel sign-in popup will not click, use the browser link above instead of the Cursor MCP prompt.
